# Security policy

Report suspected credential exposure, trust-policy bypasses, organization
escape paths, or destructive workflow flaws privately through GitHub's
**Security** tab using **Report a vulnerability**. Include the affected commit,
reproduction steps, expected and actual behavior, and the known blast radius.
Do not include live credentials, Terraform state, account contacts, or customer
data in a public issue.

Security fixes are applied to the default branch. Historical screenshots and
phase tags are evidence captures, not maintained release lines.
